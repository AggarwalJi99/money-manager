# Money Manager — Project Plan

## Goal

Build a simple Android app for managing personal finances,
bills and invoices.

## Version 1 — Personal Finance

### Dashboard
- Current balance
- Total income
- Total expenses
- Monthly summary

### Transactions
- Add income
- Add expense
- Transaction history
- Categories
- Date
- Notes

### Reports
- Monthly income
- Monthly expenses
- Category-wise spending
- Simple charts

## Version 2 — Bills & Invoices

- Add bills
- Bill due dates
- Paid / unpaid status
- Invoice details
- Store/vendor information
- Bill photo

## Version 3 — Smart Features

- Scan bill/invoice
- OCR
- Automatically extract information
- AI financial assistant
- Spending insights

## Version 4 — Sharing & Backup

- Backup
- Restore
- Optional cloud sync
- Prepare stable version for friends to test

## Development Rule

Build small features one at a time.

Learn while building.

Test every feature before adding the next one.
